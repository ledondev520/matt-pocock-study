7. Full licence: ```licence``` with one line `id: mattpocock-skills|archify`. The build inserts the upstream LICENSE verbatim from `third_party/<id>/LICENSE` (sha256-checked in `scripts/licences.mjs`) into the page, its `.md` download and `llms-full.txt`. Every page that adapts a reused MIT source states its copyright line and ends with this block; never type licence text into content. Archify needs no block: any page whose head or body embeds an Archify diagram gets the Archify licence appended by the build (home pages too), unless the page already has an `id: archify` block. Diagram SVG files start with the one comment the validator accepts, the Archify licence generated by `archifySvgComment()`. That comment is committed content in each `public/diagrams/*.svg`: `npm run diagrams` writes it on export, and tests check it byte for byte. `node scripts/diagrams/licence-comments.mjs --check` only verifies it and never changes a file: it accepts only regular, single-link `<id>.<zh|en>.svg` files inside the directory (any symbolic link, hard link or other entry fails), opens them read-only, and on a missing or different comment fails and prints the exact comment to paste in by hand.

Quote rules (copyright): only quotes listed in OUTLINE for that page, each ≤ 2 sentences with its URL and date. Everything else is our own words. Never invent "Matt said". No other copied text.
