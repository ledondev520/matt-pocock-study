# Knowledge base data format · 学习知识库数据格式

`data/knowledge-base.json` holds every published knowledge base entry. It is generated by
`scripts/kb/sync.ts` from the maintainers' notes after the publication gate passes, and checked
again by the build (`validateFeed` in `scripts/kb/feed.ts`). Other features (timeline, search)
should read this file rather than the notes.

```json
{
  "version": 2,
  "entries": [
    {
      "id": "matt-notes-2026-10-27-2114749427889979405",
      "date": "2026-10-27",
      "source": "matt-notes",
      "title": "One-line title",
      "body": [
        { "text": "Our own words, at most a short quotation. " },
        { "text": "original", "href": "https://x.com/mattpocockuk/status/2114749427889979405" },
        { "text": "." }
      ],
      "url": "https://x.com/mattpocockuk/status/2114749427889979405"
    }
  ]
}
```

| Field | Meaning |
|---|---|
| `version` | Always `2`. A breaking change bumps it. |
| `entries` | Sorted by `date`, newest first; within one date, in note order. Group by `date` for a day view. |
| `id` | Stable and unique: `<source>-<date>-<status id>`; for an original without a numeric id, an 8-digit hex FNV-1a hash of `url`. The same post noted twice on one day gets `-2`, `-3`. Used as the HTML anchor on the page (`/zh/knowledge#<id>`). It stays the same when the title or body is edited. |
| `date` | `YYYY-MM-DD`, the day the note was written (Beijing time). |
| `source` | `matt-notes` (notes on Matt Pocock's public posts) or `team` (what the team learned elsewhere). Labels and link rules live in `SOURCES` in `scripts/kb/feed.ts`. |
| `title` | Plain text. |
| `body` | Plain-text segments; a segment with `href` is a link. Render text escaped; never as HTML. Concatenate `text` for search. |
| `url` | The original post. `matt-notes`: `https://x.com/mattpocockuk/status/<id>`. `team`: any `https://x.com/<handle>/status/<id>` or a `https://github.com/<owner>/<repo>…` page. Always also present as a link in `body`. |

Every link in `body` is on an allow-list: the entry's own source's originals (a `matt-notes` entry
cannot link to other X accounts or other GitHub repositories), plus `github.com/mattpocock/…`,
`www.aihero.dev` and `www.totaltypescript.com`. Entries are in Chinese.

## How a note becomes an entry · 笔记怎样变成条目

- Only the part before the usage marker is published. The marker is `用法` or `用途`, then any colon;
  Markdown emphasis, spaces and invisible characters may sit inside it (`**用法**：`, `用途︰`).
- An entry with no marker, a marker in its title, or anything else that still reads like a `用…`
  section after folding (NFKC, invisible characters removed) is skipped and logged, not published.
- The gate checks every field as written, folded, and with Markdown removed, and then the entry as
  the page shows it (title plus all segment texts joined). Private names are also matched with every
  space and punctuation mark removed. Any finding blocks the whole batch.
