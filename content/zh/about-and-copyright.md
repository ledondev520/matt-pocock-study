## 这是谁的学习站

本站是非官方、非商业的学习整理，由维护者独立编写。它不是 Matt Pocock 本人的网站或官方译本，没有隶属或背书关系；公开发布前仍需维护者审核。

## 来源到哪里为止

资料快照截止 2026-10-20，范围包括公开帖子、公开文章索引与已核实许可的开源仓库。本站提供自己的解释、原创例子和少量短引文，不把公开可读当成复制许可。

未采用的材料不进入正文或下载版本。原始归档与评论不作为全文发布；课程、cohort、工作坊内容不取材。开源工具的许可不能扩展到它所服务的其他作品。

## 四种标记，四种含义

下面用本站原创的「保存失败」情境解释标记。只有 quote 块里的英文是所列作者原话，示例解释不归到 Matt 名下。

<!-- compare -->
| 标记 | 如何阅读 |
| --- | --- |
| 带链接的短引文 | 核对英文原话、作者、URL 与日期 |
| 本站译意 | 我们对紧邻引文的中文释义，不是另一句原话 |
| 本站推论 | 例如建议先复现保存失败，再选择检查 |
| MIT 改编 | 例如改编交接字段，写清源文件、改动与许可 |

该署名请求说明尊重归属的必要，不是向本站授予许可，也不是推荐本站。AI 生成的句子不能加上作者名字变成原话。

```note
kind: inference
本站推论：引文回答「作者写了什么」，练习回答「我们建议怎么试」。两者分开，读者才能核对来源，并自行判断方法是否适合。
```

## 已知缺口与更正

较早回复样本不全，图片与视频内容未独立核实；链接的当前可用性、最新 API 兼容性未保证。归档观察不等于普遍结论，页面练习也不代表教学效果已经验证。

事实、译意、链接或版权有误，应更正并记录日期、修改内容与依据。专门联系渠道尚未提供；本站不编造邮箱、授权文件或与作者的合作关系。

## 练习：给一句话找位置

```exercise
title: 这句话是谁的判断
- 情境：维护者建议保存失败后保留表单输入。
- 任务：它应放进 Matt 原话、本站推论还是 MIT 改编？还缺什么证据？
answer: 这是本站建议，应标为推论；需验证失败后输入确实保留。没有原始引文就不能署名 Matt，没有取用许可结构也不应标成 MIT 改编。
```

完成标准：能区分原话、释义、判断与改编，并为真正复用指出来源和许可。署名不替代授权，非商业性质也不替代许可。
