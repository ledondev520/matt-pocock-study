# Matt Pocock study notes

[中文](README.zh-CN.md)

A bilingual (English and Chinese) study site about Matt Pocock's public teaching: his posts, articles and repositories, rewritten as short lessons in our own words.

Read it at **https://matt.withkeya.com**.

This is an unofficial, non-commercial project. It is not affiliated with or endorsed by Matt Pocock. To learn from the source, follow [Matt on X](https://x.com/mattpocockuk), read his [GitHub](https://github.com/mattpocock), and try [AI Hero](https://www.aihero.dev).

## Run it locally

Node 22.23.4+ (22.x):

```sh
npm ci
npm run dev
```

Then open the address Vite prints. Building, deploying, tests, the API and content rules are in [docs/maintainers.md](docs/maintainers.md).
